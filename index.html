O projeto por trás da agenda

O Prazo Certo é o Projeto Integrador do 2º ano do Técnico em Informática da UNASP, nas disciplinas de Desenvolvimento Web, Programação Orientada a Objetos e Banco de Dados.

A versão entregue em novembro de 2026 cobre o essencial: conta, disciplinas, atividades, filtros e conclusão. Notificação, calendário externo e aplicativo ficaram fora do escopo para caber no prazo do bimestre.

A ideia veio de uma cena comum: quatro provas na mesma semana, cada uma anotada em um lugar diferente.

O caminho de um dado

O navegador nunca fala com o SQLite. Ele chama a API, e o Flask decide o que cada usuário pode ver.

  1. NavegadorHTML, CSS e JS
  3. Flaskrotas /api
  5. DAOSQL parametrizado
  7. SQLitearquivo local

O frontend usa fetch e recebe JSON. O DAO executa SQL parametrizado, e o Flask filtra os dados pelo usuário logado.

Perguntas sobre o sistema

Respostas sobre uso, dados e escopo.

Preciso instalar alguma coisa?

Não. O sistema roda no navegador. No computador, você abre o endereço do projeto; no celular, o layout se ajusta a partir de 360 px.

Outra pessoa vê minhas atividades?

Não. Cada conta acessa apenas as disciplinas e atividades cadastradas nela. As consultas são filtradas pelo usuário que está logado.

O sistema avisa quando o prazo está chegando?

Ainda não. A data aparece na lista, mas não há e-mail, notificação ou alarme. Você precisa abrir a agenda para conferir.

Posso excluir uma disciplina com atividades dentro?

Pode. As atividades ligadas a ela são apagadas junto, por causa da exclusão em cascata configurada no banco. Se quiser guardar o histórico, marque a atividade como concluída em vez de excluir.

Como a data é guardada?

No formato AAAA-MM-DD, como texto. O SQLite não tem um tipo de data próprio, e esse formato ordena corretamente sem depender do idioma do navegador.

Dá para usar no celular e no computador?

Sim. A conta é a mesma nos dois. O layout foi testado em 360, 768 e 1200 px, e a navegação por pill continua no topo.
